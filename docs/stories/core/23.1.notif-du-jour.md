# Story 23.1 — « Notif du jour » : bandeau agrégateur quotidien

**Type** : Feature · **Statut** : Implémentée (PR 1) · **Date** : 2026-07-03

## Contexte

Le haut du feed « L'essentiel du jour » empilait plusieurs bandeaux (renudge
notif, géoloc, well-informed, Lettres). Le design handoff livre un composant
hifi : **une ligne de notification unique** sous l'app bar, où le Facteur met
en avant chaque jour une fonctionnalité peu vue, choisie selon l'état du
compte. Ce composant devient **le point d'agrégation** de ces surfaces.

## Décisions PO

- **Rotation quotidienne intelligente** : `rankKey = relevance(profil) +
  jitter(jour, id)` (ε = 0.15), déterministe, stable intra-jour.
- **Un seul message visible**, jusqu'à **3/jour** ; le suivant après
  complétion d'action **ou** dismiss.
- CTA in-place (Serein) : repli → le prochain message éligible apparaît.
- Message « Config » (onboarding 3/5) **sorti de la rotation** → CTA fort
  « Ma configuration » avec barre de progression dans `profile_screen.dart`.
- PR 1 absorbe les **3 nudges inline** (renudge, well-informed NPS, géoloc)
  et supprime leurs widgets standalone. Lettres → PR 3.
- Fix CTA : Source → `RouteNames.addSource` ; Premium → `?add=1`
  (auto-ouverture de la feuille d'ajout dans `SubscriptionsScreen`).

## Architecture

`apps/mobile/lib/features/notif_du_jour/`

- `models/notif_du_jour_message.dart` — data class (`icon`, `tint`
  ocre/green/steel, `title`, `ctaLabel`, `onTap`, `onDismissed`,
  `customBodyBuilder`) + catalogue des 9 messages (6 profil + 3 nudges).
- `providers/notif_du_jour_provider.dart` — éligibilité (providers existants
  réutilisés : `*ShouldShowProvider`, `userSourcesProvider`,
  `eligibleSubscriptionSourcesProvider`, `veilleActiveConfigProvider`,
  `tourneeOrderPrefsProvider`, `sereinToggleProvider`) + relevance + jitter
  FNV(`id#jour`) → file ordonnée d'ids. Fallback `recommencer` (0.1) : file
  jamais vide. Async non résolu ⇒ inéligible.
- `providers/notif_du_jour_day_store.dart` — persistance
  `notif_du_jour_state_v1` (`{day, consumed[]}`), reset à minuit, cap 3/jour.
- `widgets/notif_du_jour_card.dart` — rendu hifi (surface, radius 14, ombre,
  carré icône 34, DM Sans 13.5, CTA-lien + flèche, croix 30), repli
  `AnimatedSize`+opacité+translation 300ms, reduced-motion instantané,
  press scale 0.98 + haptique.
- `widgets/well_informed_inline_body.dart` — mini-form NPS 1..10 en
  `customBodyBuilder`.

### Relevance (calibrable PO)

| id | relevance |
|---|---|
| notif_renudge | 0.9 |
| well_informed | 0.85 |
| geoloc | 0.7 |
| source | `clamp01((3 − trustedCount)/3)` |
| premium | `min(1, eligibleUnlinked/3)` |
| veille | 0.6 |
| tournee | 0.5 |
| serein | 0.4 |
| recommencer | 0.1 (fallback) |

### Cohabitation

La carte ne s'affiche que si `firstImpressionSlotProvider == none`
(l'orchestrateur ne garde que les modales iOS-add-to-home / notif) et si le
bandeau Lettres n'est pas affiché cette session
(`lettresBannerVisibleThisSessionProvider`). Les caps existants des nudges
absorbés avancent à la consommation (`recordRenudgeShown`, `recordShown`,
`skip`).
