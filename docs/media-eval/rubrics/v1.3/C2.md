# C2 — Sourçage et vérification (15 points · 5 niveaux · Rigueur informationnelle)

> Critère **sur corpus** (§5.4) : l'évaluation repose sur un échantillon
> d'articles informatifs (20–40 selon le volume du média). Sans corpus
> instrumenté et sans autre signal exploitable, rends `donnees_insuffisantes`
> → N/A.

## Barème (méthodologie v1.3 §4.1, verbatim)

**Définition** : Le média cite ses sources de manière régulière, les croise
lorsque nécessaire, et distingue les faits établis des allégations ou hypothèses.

**Réf.** : Charte de Munich, devoir 3 ; FIJ 2019, art. 3 ; NewsGuard, critère 2.

**Signaux observables** :
- Présence de sources nommées (nom, titre, institution) dans les articles
  informatifs + lien de redirection cliquable vers la source citée.
- Usage du conditionnel ou de formulations prudentes (« selon… », « d'après… »,
  « il/elle aurait… ») pour les informations non confirmées
- Nombre moyen de sources indépendantes par article factuel (objectif : ≥ 2)
- Attribution claire des citations directes ; absence de reformulations non
  attribuées

**Barème de notation (5 niveaux)** :

| Score | Attribution |
|---|---|
| 15 | Sources nommées (nom, titre, institution) dans la quasi-totalité des articles informatifs ; ≥ 2 sources indépendantes en moyenne par article factuel ; liens cliquables systématiques vers la source primaire ; attribution systématique des citations ; formulations prudentes constantes sur les informations non confirmées. |
| 11 | Sources nommées dans une large majorité des articles ; liens fréquents mais non systématiques ; prudence lexicale majoritaire ; reformulations non attribuées rares et sans effet sur le sens. |
| 7 | Sourçage irrégulier (environ un article sur deux) ; recours fréquent à des sources génériques (« selon nos informations », « des experts ») ; liens rares ; confusion occasionnelle entre fait établi et allégation. |
| 3 | Sourçage minoritaire ; reprises non attribuées fréquentes ; allégations régulièrement présentées comme des faits établis. |
| 0 | Aucune pratique de sourçage identifiable sur l'échantillon. |

Protocole d'échantillonnage : voir section 5.4.

## Types de signaux attendus en entrée

| `type_signal` | Contenu de `valeur` |
|---|---|
| `articles` (bloc corpus) | échantillon d'articles informatifs (url, date, rubrique) avec métriques de sourçage : taux de sources nommées, moyenne de sources indépendantes/article, présence de liens cliquables, taux d'attribution des citations, usage des formulations prudentes |

> Le registre `TYPE_SIGNAUX` v1.3 pour C2 (bloc corpus) est étendu à la
> construction de la collecte d'échantillons d'articles (harness batch 2).

## Comment déterminer le niveau

- Le niveau se lit sur l'**ensemble de l'échantillon**, pas sur un article isolé.
  Rapporte tes affirmations aux `signal_ids` du bloc corpus.
- « Quasi-totalité », « large majorité », « environ un article sur deux »,
  « minoritaire » sont les seuils verbatim du barème ; applique-les aux taux
  observés sur l'échantillon.
- Échantillon absent ou trop maigre pour être représentatif → `donnees_insuffisantes`.

## Sortie structurée

`determinations` :

```json
{ "niveau": 0 | 1 | 2 | 3 | 4 }
```

| `niveau` | Score dérivé (code) | Libellé barème |
|---|---|---|
| 4 | 15 | Sourçage quasi-total, ≥ 2 sources indép., liens systématiques, citations attribuées |
| 3 | 11 | Large majorité sourcée, liens fréquents, reformulations non attribuées rares |
| 2 | 7 | Sourçage irrégulier (~1 sur 2), sources génériques fréquentes, liens rares |
| 1 | 3 | Sourçage minoritaire, reprises non attribuées fréquentes |
| 0 | 0 | Aucune pratique de sourçage identifiable |
